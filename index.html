解壓遊戲廳

六款動動腦的小遊戲，每款都有 50 關、從簡單開始。
慢慢想、慢慢玩，過關的感覺最解壓。

所有聲音都是即時合成的，輕輕的，放心開著玩。

水排序

第 1 關
第 1 / 50 關

點一支試管拿起來，再點另一支倒過去。
只能倒在同色水面上，或空試管裡。

滑塊解謎

步數 0
第 1 / 50 關

拖動木塊：橫的只能左右滑、直的只能上下滑。
把紅色 ★ 木塊滑到右邊出口就過關。

接管線

0%
第 1 / 50 關

從一個圓點拖到同色的另一個圓點，拉出一條管線。
管線不能交叉，而且要鋪滿每一格才算過關。

一筆畫

0 / 0 條線
第 1 / 50 關

點一個圓點開始，再依序點相鄰的圓點（也可以按住拖過去）。
每條線只能走一次，走完所有線就過關。從奇數線的點出發會比較順喔。

推箱子

步數 0
第 1 / 50 關

用方向鍵推箱子（也可以在棋盤上滑動）。
小心別把箱子推到牆角，會拉不回來喔。

數獨

簡單
第 1 / 50 關

每一行、每一列、每個 2×3 區塊，都要有 1 到 6 各一個。填錯會變紅色。
